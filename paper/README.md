# Paper source (IEEEtran conference)

Honest, reframed conference-paper source for the Self-Healing SDN project.
Status and the full fix pipeline live in `../PAPER_ROADMAP.md`.

## Files
- `main.tex` — the paper. Every number is tagged: `% [VERIFIED ...]` = produced by
  a repo artifact; `% [TODO ...]` = still to do (mostly fix #5/#6).
- `references.bib` — **all entries verified 2026-07-01 (fix #6)** against the
  publisher record. Two unverifiable thesis entries were removed and one
  mis-attributed entry corrected (see the file header). The paper now uses BibTeX
  (`\bibliography{references}`), so run `bibtex` in the build.
- `figures/` — `confusion_matrix.png`, `baseline_comparison.png` (generated by the
  evaluation scripts), `Telemetry_Graph.png` (original).

## How to compile
No TeX toolchain is installed on the dev VM (and its disk is full), so build it
elsewhere:

**Overleaf (easiest):** create a project, upload `main.tex`, `references.bib`, and
the `figures/` folder. IEEEtran is built in. Set `main.tex` as the main document.

**Local TeX Live:**
```bash
pdflatex main
bibtex   main
pdflatex main
pdflatex main
```

## What is already honest/reframed (fix #4)
- Title/abstract present a **closed-loop self-healing system**; RL is a design
  choice, not the headline.
- Evaluation reports **leakage-free held-out** metrics (fix #2) and a **baseline
  comparison** (fix #3) showing simple classifiers match the RL agent.
- A **Threats to Validity** section states plainly: it's classification not
  sequential RL; the zero-throughput label heuristic; the latency proxy; small scale.
